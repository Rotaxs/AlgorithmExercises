# 贪心

## CF1526C2 Potions 反悔贪心 + 小根堆

> 题目大意：初始生命值为 0，给定一个长度为 $n$ 的药物序列（有正有负），从第一个数开始，可以选择服用药物和放弃，要求生命值始终不小于 0，求能服用的最大药物数

最直接的想法是只要不会使得生命值小于 0，都选择服用药物，但是考虑这种情况，服用一个药物（非常小的负数）后，生命值变得很小或者为 0，后面出现了一连串像是 -1, -2 这种非常大的负数，这就导致些非常大的负数无法服用。这里更优的方案显然是不服用前面这个小的负数，而服用后面多个大的负数

此题可以考虑反悔贪心，当遇到负数药物时，将其存下来，无论是什么药物都先考虑服用，当服用后生命值小于 0 时，说明当前药物不可服用，或者取消（反悔）之前服用的一个负数的药物，显然取消的这个药物越小（绝对值越大），对后面服用更多的药物更有利，因此只需要取消最小的那个药物的作用即可

```cpp
void solve() {
    int n;
    cin >> n;
    priority_queue<int, vector<int>, greater<int>> pq;
    ll sum = 0, ans = 0;
    for (int i = 0; i < n; ++i) {
        int a;
        cin >> a;
        if (a < 0) {
            pq.push(a);
        }
        sum += a;
        ++ans;
        if (sum < 0) {
            sum -= pq.top();
            pq.pop();
            --ans;
        }
    }
    cout << ans << endl;
}
```
