# 计算几何

## 距离公式与坐标变换

设两个点为 $P(x_1, y_1)$，$Q(x_2, y_2)$，则

- **曼哈顿距离**：$|x_1 - x_2| + |y_1 - y_2|$
- **切比雪夫距离**：$\max(|x_1 - x_2|, |y_1 - y_2|)$

核心恒等式：

- $|a| + |b| = \max(|a + b|, |a - b|)$
- $\max(|a|, |b|) = \frac{|a + b| + |a - b|}{2}$

> [!note]
> 补充两个恒等式
> - $\max(a, b) = \frac{a + b + |a - b|}{2}$
> - $\min(a, b) = \frac{a + b - |a - b|}{2}$

通过这两个恒等式，可以实现曼哈顿距离和切比雪夫距离的转换

进行坐标变换，$u = x + y$，$v = x - y$，则

- $|x_1 - x_2| + |y_1 - y_2| = \max(|u_1 - u_2|, |v_1 - v_2|)$
- $\max(|x_1 - x_2|, |y_1 - y_2|) = \frac{|u_1 - u_2| + |v_1 - v_2|}{2}$

### [ABC460A](https://atcoder.jp/contests/abc480/tasks/abc480_a) ADjacent

> 题目大意：给定一个 2 x 2 的矩阵，向其中四个格子分别填入 A、B、C、D 四个字母，判断所给矩阵中 A 和 D 是否相邻

考虑曼哈顿距离，相邻意味着曼哈顿距离为 1

### 求曼哈顿距离最远点对

> 给定 $N$ 个点，求 $\max_{i,j}(|x_i - x_j| + |y_i - y_j|)$

进行坐标变换后得到 $\max_{i,j}(|x_i - x_j| + |y_i - y_j|) = \max(\max u - \min u, \max v - \min v)$

这样只需维护四个最值即可

### 切比雪夫距离求和

> 给定 $N$ 个点，计算第 $i$ 个点到其余点的切比雪夫距离之和 $S_i = \sum_{j = 1}^{N}\max(|x_i - x_j|, |y_i - y_j|)$

进行坐标变换，得到 $S_i = \frac{1}{2}\left(\sum_{j = 1}^{N}|u_i - u_j| + \sum_{j = 1}^{N}|v_i - v_j|\right)$

排序后处理前缀和即可

### 曼哈顿距离和最小化

> 给定 $N$ 个点，求一个位置 $P(x, y)$，使得该点到这个 $N$ 个点的曼哈顿距离最小

即求 $\min_{x, y} \sum_{i = 1}^{N}(|x_i - x| + |y_i - y|)$

横纵坐标显然可以拆开来求，显然当 $x = \text{median}(x_i)$，$y = \text{median}(y_i)$ 时，结果最小

用对顶堆维护中位数即可
