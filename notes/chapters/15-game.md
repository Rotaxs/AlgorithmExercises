# 博弈

## Nim 游戏

[**2026 ICPC Nanchang Invitational Contest H**](https://codeforces.com/gym/106551/problem/H)

> 题目大意：初始给定一个长度为 $n$ 的非负整数序列 $a$ 和一个正整数 $k$，两人轮流选择一个数 $x$ 和序列中的一个数 $a_y$，满足 $0 \leq x \leq \min(k, a_y)$，然后令 $k \leftarrow x$，$a_y \leftarrow a_y - x$，当某人选择 $x = 0$ 时失败，游戏结束

$k$ 是不增的，首先考虑先手选 $x = 1$，那么后面选择时为了保证不败，每个人都只能选择 $1$，因此操作次数为序列中所有数的和 `sum`，当 `sum` 为奇数时先手必胜

当 `sum` 为偶数时，先手为了确保自己不败，肯定不能选择奇数，因此只能选择偶数，而后手为了保证自己操作完后，剩余数的和不是奇数（否则回到原来先手必胜的状态），也只能选择偶数

接下来可以考虑对序列中的每一个数进行分组，由于必须选择偶数，我们可以先两两一组，即令 $a_i \leftarrow \lfloor \frac{a_i}{2} \rfloor$，初始的 $k$ 也相应地变为 $\lfloor \frac{k}{2} \rfloor$，这是这个问题变成了一个新的相似的问题，讨论 $\sum\lfloor \frac{a}{2} \rfloor$ 的奇偶即可

当和为奇数时，先手只需要选择 2，这时后手为了保证不败，一定不能选择 1，但是如果选择 2，根据前面相似的讨论，后手还是会败（显然在这个情况下需要满足初始的 $k \geq 2$）

> [!note] 为什么向下取整？
> 如果 $a_i$ 均为偶数，那么恰好可以两两分组，此时如果 $\Sigma a/2$ 为奇数，那么先手可以选择 $k' = 1$（即原来的 $k = 2$，也即现在的一组），从而保证先手必胜。这是选完所有组后恰好不剩下任何数的情况
> 而如果存在 $a_i$ 为奇数，这表示选完所有的组后，还剩下一些数，这些数无法成组，都是“奇数”，接下来后手一定会选择某个奇数
> 前面说过，如果某个人在 `sum` 为偶数的情况下先选择了奇数，那么其必败
> 因此无论是否全部都能整除，只需要讨论恰好分好组的部分即可

如果和还是偶数，可以进一步地将新的序列分组，即得到新的序列 $\{\lfloor a_i/4 \rfloor\}$，然后同上讨论即可，这时需要保证 $k \geq 4$

因此，只需要依次 $\sum\lfloor a_i / 2^p \rfloor$ 的奇偶性，只要出现了 $p$ 使得和为奇数，那么先手必胜，否则后手必胜

```cpp
void solve() {
    ll n, k; cin >> n >> k;
    vector<ll> a(n + 1);
    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
    }
    for (int p = 0; p <= 32; ++p) {
        if ((1ll << p) > k) break;
        ll cnt = 0;
        for (int i = 1; i <= n; ++i) {
            cnt += (a[i] >> p);
        }
        if (cnt & 1) {
            cout << "Alice" << endl;
            return;
        }
    }
    cout << "Bob" << endl;
}
```

更进一步，每一个 $p$，都相当于将原序列中每一个数右移 $p$ 为，然后将所有的数相加，判断二进制表示的最末一位是否为 1（奇数）

实际上，可以通过异或和直接得到每一位的 1 的个数，然后取最末的 1，判断这个 1 所在位置表示的十进制数是否小于等于 $k$ 即可，也就是 $lowbit$

```cpp
void solve() {
    int n, k; cin >> n >> k;
    int s = 0;
    for (int i = 1; i <= n; ++i) {
        int x; cin >> x;
        s ^= x;
    }
    if (s != 0 && (s & -s) <= k) cout << "Alice" << endl;
    else cout << "Bob" << endl;
}
```
